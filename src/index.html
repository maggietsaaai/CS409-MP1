Projects

SkinMatch
— Skincare Recommendation Web App

Built a Flask and MySQL web app that recommends skincare products based on users’ goals and skin types. Implemented account, review, and routine-management features and processed over 63,000 Sephora reviews for testing and recommendations.

NYCU Campus Autonomous
and VR Driving Simulation

Recreated the NYCU campus as a driving environment using OpenStreetMap, RoadRunner, Blender, Unreal Engine, and CARLA. The simulation supports autonomous driving, VR driving with a Logitech steering wheel, and a real-time minimap.

Student Time Allocation
and Academic Performance Analysis

Conducted a survey examining how students’ sleep, study, and leisure time relate to academic performance. Cleaned the responses and used Python to perform correlation, regression, and statistical visualization.
